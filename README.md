# Astra Hacker

현재 작업 기준은 사용자 제공 **ITfest6.zip**입니다. 시작 화면의 작은 **튜토리얼 플레이** 버튼에서 기존 튜토리얼 연습 모드로 진입합니다. 비밀번호 설정 후 제한 시간 없이 연습할 수 있으며, 싱글 난이도 목록에는 쉬움·보통·어려움·챌린지만 표시합니다.

튜토리얼 방어는 랜섬웨어 → 재전송 → 가로채기 → 피싱 → 스푸핑 순서로 반복합니다. 5종을 한 번씩 경험하면 성공 여부와 관계없이 모든 비밀번호 힌트를 공개합니다. 내 공격 차례에 정답을 입력하면 튜토리얼 완료 화면이 나옵니다. `다음 방어 연습` 버튼으로 방어 체험을 빠르게 이어갈 수 있습니다.

나가기는 한 번 누르면 즉시 시작 화면으로 돌아갑니다. 현재 레벨은 방어 기록 칸 오른쪽 위에 표시합니다. 멀티 DDoS는 내 공격 선택 중 여러 개 사용할 수 있으며 `Lv. 기본값 + 사용 수`만큼 실제 방어 난이도도 올라갑니다. 방어가 끝나면 성공 여부와 관계없이 해제됩니다.

챌린지는 비밀번호/내 IP 정보를 숨기고 남은 목숨·클리어·상대 IP·레벨만 표시합니다. 결과 안내는 ‘다음 공격이 옵니다!’로 표시합니다.

중세 건축과 별빛을 배경으로 보안 공격과 방어 미니게임을 주고받는 축제용 웹게임. React + Express + Socket.IO.

## 실행

```sh
npm install
npm run dev
```

http://localhost:3000 에 접속한다. 다른 노트북은 터미널에 출력된 Network 주소를 사용한다. 두 노트북이 통신 가능한 같은 네트워크에 있어야 한다.

## 플레이

- 싱글: 난이도 선택 → 비밀번호 설정 → 튜토리얼 → 공격과 방어 미니게임 반복. 튜토리얼 난이도에서는 모든 공격과 아이템을 제한 시간 없이 연습할 수 있다.
- 쉬움/보통/어려움은 방어 3/4/6회마다 힌트, 초기 방화벽 2/1/0개. 쉬움의 방어 제한 시간은 랜섬웨어 15초/기타 10초, 보통은 랜섬웨어 10초/기타 7초다.
- 챌린지: 목숨 3개로 방어만 연속 진행하며 클리어 개수 기록.
- 멀티: 방 만들기(내 비밀번호 설정) 또는 5자리 방 코드 참가 → 참가자 비밀번호 설정 → 양쪽 튜토리얼/준비 완료 → 방장 시작.
- 비밀번호는 숫자 4자리, 중복과 선행 0 허용. 선공은 무작위. 내 공격 차례에 정답 입력 시 승리.
- 스푸핑/랜섬웨어/가로채기/피싱/재전송 공격은 기본적으로 5/7/5/5/5초 미니게임. 재전송 방어는 방향키와 WASD를 모두 지원한다. 실패하면 공격자가 비밀번호 힌트 한 자리를 얻는다.
- 일반 공격 사용 후 다음 내 공격 차례 2회 동안 재사용 불가. 브루스 포스는 예외. 양쪽 공방 1회씩이 1턴이며 3턴마다 난이도만 상승한다.
- 공격 제한 시간은 10초. 멀티 시간 초과 시 가능한 보안 공격/경로를 무작위 선택한다. 싱글은 비밀번호 입력(확보한 힌트+임의 숫자) 또는 건너뛰기를 무작위 선택한다.
- 멀티 보급 상자: 공격 대신 선택하며 차례 소비. DDoS 35%, VPN 35%, 방화벽 20%, 꽝 10%. 사용 후 다음 내 공격 차례 2회 동안 재사용 불가. 일반 싱글 상자는 쿨타임 없음.
- 멀티 피싱: DDoS 45%, VPN 45%, 방화벽 10%로 팝업을 생성하며 성공하면 표시된 아이템 1개 지급.
- 일반 싱글 상자/피싱: 꽝 80%, 방화벽 20%. 챌린지 피싱은 100% 꽝이며 성공 시 클리어 수만 증가한다. VPN과 DDoS는 싱글에서 지급하지 않고 아이템 목록에도 표시하지 않는다.
- 챌린지는 아이템 창을 숨기고 진행 시간만 표시한다. 일반 싱글과 멀티의 아이템 창은 유지한다.
- VPN과 DDoS는 멀티에서 사용 버튼을 눌러 수동 사용한다. VPN은 보상 획득이나 스푸핑 방어 성공으로 자동 소모되지 않는다. 방화벽만 실패 시 자동 소모한다.
- 일반 싱글 방어 실패 시 방화벽이 있으면 1개 소모, 없으면 내 비밀번호 1자리 노출. 4자리 모두 드러나면 즉시 패배한다. 챌린지는 목숨 3개 규칙을 유지한다.
- IP는 3자리 숫자이며 싱글·멀티·챌린지 모두 스푸핑 방어 중에는 상대 IP 표시를 숨긴다. 상대 IP는 공격 전 대결 화면에서 기억한다.
- 랜섬웨어 기본 파일 3개, 재전송 기본 화살표 5개. 입력은 서버 응답 대기 없이 즉시 반영하고 서버가 순서/시간을 검증한다.
- 내 비밀번호 노출도, 게임 진행 시간, 승리/패배 전용 화면을 제공한다. 시스템 로그 패널은 표시하지 않는다.

현재 선택한 해석과 미확정 사항은 [AGENTS.md](./AGENTS.md)에 기록했다. 3턴별 자동 아이템 보상은 없다. DDoS는 멀티 상대의 다음 미니게임 한 번에 적용한다. 증가량은 화면 크기를 위해 +8까지로 제한한다.

## 검증

```sh
npm test
node scripts/smoke.mjs
node scripts/render-check.mjs
npm run build
```

통신 테스트는 실행 중인 서버를 사용한다. 서버는 방 입장/준비, 미니게임 순서와 제한 시간, 아이템, 힌트와 승패를 판정한다. 클라이언트에는 본인 비밀번호와 획득한 상대 힌트만 보낸다.

빌드 후 `npm start`로 정적 화면과 게임 서버를 함께 실행할 수 있다. 방과 기록은 메모리에만 저장되며 서버 재시작 시 초기화된다. 참가자 퇴장이나 연결 종료 시 방이 종료된다.
