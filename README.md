# Astra Hacker

중세 건축과 별빛을 배경으로 보안 공격과 방어 미니게임을 주고받는 축제용 웹게임. React + Express + Socket.IO.

## 실행

```sh
npm install
npm run dev
```

http://localhost:3000 에 접속한다. 다른 노트북은 터미널에 출력된 Network 주소를 사용한다. 두 노트북이 통신 가능한 같은 네트워크에 있어야 한다.

## 플레이

- 싱글: 난이도 선택 → 비밀번호 설정 → 공격(비밀번호 입력/건너뛰기, 10초)과 방어 미니게임 반복.
- 쉬움/보통/어려움은 방어 3/4/6회마다 힌트, 초기 방화벽 2/1/0개.
- 챌린지: 목숨 3개로 방어만 연속 진행하며 클리어 개수 기록.
- 멀티: 방 만들기(내 비밀번호 설정) 또는 5자리 방 코드 참가 → 참가자 비밀번호 설정 → 양쪽 준비 → 방장 시작.
- 비밀번호는 숫자 4자리, 중복과 선행 0 허용. 선공은 무작위. 내 공격 차례에 정답 입력 시 승리.
- 스푸핑/랜섬웨어/가로채기/피싱/재전송 공격은 각각 5/7/5/5/5초 미니게임. 실패하면 공격자가 비밀번호 힌트 한 자리를 얻는다.
- 같은 공격 연속 사용 금지. 브루스 포스는 예외. 양쪽 공방 1회씩이 1턴이며 3턴마다 난이도 상승.
- VPN과 방화벽은 필요 시 자동 소모, DDoS는 수동 사용. 피싱 성공 시 아이템 3종 지급.

현재 선택한 해석과 미확정 사항은 [AGENTS.md](./AGENTS.md)에 기록했다. 3턴별 선택 보상 미니게임은 미구현이며 난이도 상승만 적용한다. DDoS는 다음 미니게임 한 번, 싱글에서는 내 다음 방어에 적용한다. 증가량은 화면 크기를 위해 +8까지로 제한한다.

## 검증

```sh
npm test
node scripts/smoke.mjs
npm run build
```

통신 테스트는 실행 중인 서버를 사용한다. 서버는 방 입장/준비, 미니게임 순서와 제한 시간, 아이템, 힌트와 승패를 판정한다. 클라이언트에는 본인 비밀번호와 획득한 상대 힌트만 보낸다.

빌드 후 `npm start`로 정적 화면과 게임 서버를 함께 실행할 수 있다. 방과 기록은 메모리에만 저장되며 서버 재시작 시 초기화된다. 참가자 퇴장이나 연결 종료 시 방이 종료된다.
